Scenario & Frontier Trap
Business Scenario & Problem

When a user asks a question in an AI assistant, the query is embedded into a dense vector (e.g. 4-dimensional here for illustration, or 384/1536 in prod). We retrieve the top most semantically relevant documentation chunks.

⚡ The Frontier Trap (Why LLMs Fail)

4. Queries Executed (Candidate vs Golden Ground Truth)

Beautified & Syntax Highlighted
Database Engine Context: This query was executed and profiled on DuckDB 2.0 In-Memory Engine with equivalent analytical syntax and execution verification on PostgreSQL 18.7 + Extensions (Docker Compose).
Candidate SQL Executed by gemini-3.8-flash-low (Runtime on 1M Rows: 9.38 ms) 
WITH scored_docs AS
  (SELECT doc_id,
          title,
          embedding,
          array_cosine_similarity(embedding, [0.9, 0.1, 0.25, 0.0]::FLOAT[4]) AS cosine_score
   FROM doc_embeddings)
SELECT doc_id,
       title,
       round(cosine_score, 4) AS similarity_score
FROM scored_docs
ORDER BY cosine_score DESC
LIMIT 2;
Golden Reference Ground Truth SQL (Runtime on 1M Rows: 9.15 ms)
