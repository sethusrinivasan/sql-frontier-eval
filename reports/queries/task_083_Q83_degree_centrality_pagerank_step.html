1. Analytical Significance & What It Means

Scenario & Frontier Trap
Business Scenario & Problem

Social network influence and API hub criticality are determined by node in-degree centrality (number of inbound links from distinct entities).

⚡ The Frontier Trap (Why LLMs Fail)

Counting total edges without filtering distinct source nodes allows a single spammer to inflate influencer metrics.

Prompt / User Request Given to Model

4. Queries Executed (Candidate vs Golden Ground Truth)

Beautified & Syntax Highlighted
Database Engine Context: This query was executed and profiled on DuckDB 2.0 In-Memory Engine with equivalent analytical syntax and execution verification on PostgreSQL 18.7 + Extensions (Docker Compose).
Candidate SQL Executed by gemini-3.8-flash-low (Runtime on 1M Rows: 0.26 ms) 
SELECT target_user_id AS influencer_id,
       count(DISTINCT follower_id) AS in_degree_centrality,
       dense_rank() OVER (
                          ORDER BY count(DISTINCT follower_id) DESC) AS influence_rank
FROM network_follows
GROUP BY target_user_id
ORDER BY influence_rank;
Golden Reference Ground Truth SQL (Runtime on 1M Rows: 0.24 ms)
