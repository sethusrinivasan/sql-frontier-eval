1. Analytical Significance & What It Means

Scenario & Frontier Trap
Business Scenario & Problem

As companies evolve, the meaning of terms like 'security' or 'remote work' shifts. Tracking the cosine distance between monthly embedding centroids reveals semantic concept drift.

⚡ The Frontier Trap (Why LLMs Fail)

Ignoring semantic drift causes older documentation to silently diverge from current employee search queries.

4. Queries Executed (Candidate vs Golden Ground Truth)

Beautified & Syntax Highlighted
Candidate SQL Executed by gemini-3.8-flash-low (Runtime on 1M Rows: 1151.99 ms) 
WITH lagged_centroids AS
  (SELECT month_date,
          centroid,
          lag(centroid) OVER (
                              ORDER BY month_date) AS prev_month_centroid
   FROM monthly_centroids)
SELECT month_date,
       centroid,
       prev_month_centroid,
       CASE
           WHEN prev_month_centroid IS NOT NULL THEN list_cosine_distance(centroid, prev_month_centroid)
           ELSE NULL
       END AS drift_distance_from_prev_month
FROM lagged_centroids
ORDER BY month_date;
Golden Reference Ground Truth SQL (Runtime on 1M Rows: 1126.27 ms) 
-- Track month-over-month semantic drift in concept centroids

SELECT month_date,
       centroid,
       lag(centroid) OVER (
                           ORDER BY month_date) AS prev_month_centroid,
       round(1.0 - array_cosine_similarity(centroid, lag(centroid) OVER (
                                                                         ORDER BY month_date)), 4) AS drift_distance_from_prev_month
FROM monthly_centroids
ORDER BY month_date;
