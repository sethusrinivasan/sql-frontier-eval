1. Analytical Significance & What It Means

Scenario & Frontier Trap
Business Scenario & Problem

High-speed network telemetry measures packet arrival jitter (variance in inter-packet delay). Jitter spikes indicate network congestion or buffer bloat.

⚡ The Frontier Trap (Why LLMs Fail)

Standard SQL datetime arithmetic truncates to milliseconds or seconds, losing high-frequency microsecond microbursts.

Prompt / User Request Given to Model
High-speed network telemetry measures packet arrival jitter (variance in inter-packet delay). Jitter spikes indicate network congestion or buffer bloat.

4. Queries Executed (Candidate vs Golden Ground Truth)

Beautified & Syntax Highlighted
Candidate SQL Executed by gemini-3.8-flash-low (Runtime on 1M Rows: 152.44 ms) 
WITH deltas AS
  (SELECT packet_id,
          captured_at,
          date_diff('microsecond', lag(captured_at) OVER (
                                                          ORDER BY captured_at), captured_at) AS delta_microseconds
   FROM packet_stream)
SELECT packet_id,
       captured_at,
       delta_microseconds,
       round(stddev(delta_microseconds) OVER (
                                              ORDER BY captured_at ROWS BETWEEN 2 PRECEDING AND CURRENT ROW), 2) AS rolling_jitter_stddev
FROM deltas
ORDER BY captured_at;
Golden Reference Ground Truth SQL (Runtime on 1M Rows: 145.25 ms) 
-- Compute inter-packet arrival delta in microseconds and identify variance
 WITH deltas AS
  (SELECT packet_id,
          captured_at,
          date_diff('microsecond', lag(captured_at) OVER (
                                                          ORDER BY captured_at), captured_at) AS delta_microseconds
   FROM packet_stream)
SELECT packet_id,
       captured_at,
       delta_microseconds, -- Measure moving jitter variance over last 3 packets
 round(stddev(delta_microseconds) OVER (
                                        ORDER BY captured_at ROWS BETWEEN 2 PRECEDING AND CURRENT ROW), 2) AS rolling_jitter_stddev
FROM deltas
ORDER BY captured_at;
