4. Queries Executed (Candidate vs Golden Ground Truth)

Beautified & Syntax Highlighted
Database Engine Context: This query was executed and profiled on DuckDB 2.0 In-Memory Engine with equivalent analytical syntax and execution verification on PostgreSQL 18.7 + Extensions (Docker Compose).
Candidate SQL Executed by gemini-3.8-flash-low (Runtime on 1M Rows: 299.07 ms) 
WITH point_distances AS
  (SELECT p.point_id,
          p.coord,
          c.cluster_id,
          array_distance(p.coord, c.center) AS dist,
          row_number() OVER (PARTITION BY p.point_id
                             ORDER BY array_distance(p.coord, c.center) ASC) AS rank_closest
   FROM data_points p
   CROSS JOIN cluster_centroids c)
SELECT point_id,
       cluster_id AS assigned_cluster,
       round(dist, 4) AS distance_to_center
FROM point_distances
WHERE rank_closest = 1
ORDER BY point_id;
Golden Reference Ground Truth SQL (Runtime on 1M Rows: 247.68 ms) 
-- Step 1: Assign each point to the closest cluster centroid via array_distance
 WITH point_distances AS
  (SELECT p.point_id,
          p.coord,
          c.cluster_id,
          array_distance(p.coord, c.center) AS dist,
          row_number() OVER (PARTITION BY p.point_id
                             ORDER BY array_distance(p.coord, c.center) ASC) AS rank_closest
   FROM data_points p
   CROSS JOIN cluster_centroids c)
SELECT point_id,
       cluster_id AS assigned_cluster,
       round(dist, 4) AS distance_to_center
FROM point_distances
WHERE rank_closest = 1
ORDER BY point_id;
