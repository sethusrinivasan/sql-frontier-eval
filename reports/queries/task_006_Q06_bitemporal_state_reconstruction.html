4. Queries Executed (Candidate vs Golden Ground Truth)

Beautified & Syntax Highlighted
Candidate SQL Executed by gemini-3.8-flash-low (Runtime on 1M Rows: 0.04 ms) 
SELECT customer_id,
       credit_limit AS limit_as_known_then,
       valid_from,
       valid_to,
       system_from,
       system_to
FROM credit_limits_audit
WHERE customer_id = 501
  AND DATE '2026-05-15' >= valid_from
  AND DATE '2026-05-15' < valid_to
  AND TIMESTAMP '2026-06-01 10:00:00' >= system_from
  AND TIMESTAMP '2026-06-01 10:00:00' < system_to;
Golden Reference Ground Truth SQL (Runtime on 1M Rows: 0.02 ms) 
-- Query credit limit effective on 2026-05-20 as known to the system on 2026-05-25 (before retroactive update)

SELECT customer_id,
       credit_limit AS limit_as_known_then,
       valid_from,
       valid_to,
       system_from,
       system_to
FROM credit_limits_audit
WHERE customer_id = 501 -- As-of Business Date: 2026-05-20

  AND DATE '2026-05-20' >= valid_from
  AND DATE '2026-05-20' < valid_to -- As-of System State: 2026-05-25

  AND TIMESTAMP '2026-05-25 00:00:00' >= system_from
  AND TIMESTAMP '2026-05-25 00:00:00' < system_to;
