4. Queries Executed (Candidate vs Golden Ground Truth)

Beautified & Syntax Highlighted
Database Engine Context: This query was executed and profiled on DuckDB 2.0 In-Memory Engine with equivalent analytical syntax and execution verification on PostgreSQL 18.7 + Extensions (Docker Compose).
Candidate SQL Executed by gemini-3.8-flash-low (Runtime on 1M Rows: 0.86 ms) 
WITH RECURSIVE task_paths AS
  (SELECT task_code,
          duration_days AS cumulative_days,
          task_code AS path_str
   FROM project_tasks
   WHERE prerequisite_code IS NULL
   UNION ALL SELECT t.task_code,
                    p.cumulative_days + t.duration_days,
                    p.path_str || ' -> ' || t.task_code
   FROM task_paths p
   JOIN project_tasks t ON p.task_code = t.prerequisite_code)
SELECT task_code,
       cumulative_days AS critical_path_duration,
       path_str
FROM task_paths
ORDER BY cumulative_days DESC
LIMIT 1;
Golden Reference Ground Truth SQL (Runtime on 1M Rows: 0.68 ms) 
-- Find the longest path (Critical Path) from START to DEPLOY
 WITH RECURSIVE task_paths AS
  (SELECT task_code,
          duration_days AS cumulative_days,
          task_code AS path_str
   FROM project_tasks
   WHERE prerequisite_code IS NULL
   UNION ALL SELECT t.task_code,
                    p.cumulative_days + t.duration_days,
                    p.path_str || ' -> ' || t.task_code
   FROM task_paths p
   JOIN project_tasks t ON p.task_code = t.prerequisite_code)
SELECT task_code,
       cumulative_days AS critical_path_duration,
       path_str
FROM task_paths
ORDER BY cumulative_days DESC
LIMIT 1;
