1. Analytical Significance & What It Means

Scenario & Frontier Trap
Business Scenario & Problem

Long PDF manuals are split into 50 chunks each. To avoid returning 5 chunks from the exact same PDF manual, we retrieve the best chunk per document and aggregate at the document level.

⚡ The Frontier Trap (Why LLMs Fail)

Returning raw chunk Top-K dominates the context window with duplicates from a single document.

Prompt / User Request Given to Model

4. Queries Executed (Candidate vs Golden Ground Truth)

Beautified & Syntax Highlighted
Candidate SQL Executed by gemini-3.8-flash-low (Runtime on 1M Rows: 459.21 ms) 
SELECT doc_id,
       doc_title,
       chunk_id,
       chunk_text,
       round(array_cosine_similarity(vec, [1.0, 0.0]::FLOAT[2]), 4) AS chunk_score
FROM document_chunks QUALIFY row_number() OVER (PARTITION BY doc_id
                                                ORDER BY array_cosine_similarity(vec, [1.0, 0.0]::FLOAT[2]) DESC) = 1
ORDER BY chunk_score DESC;
Golden Reference Ground Truth SQL (Runtime on 1M Rows: 464.20 ms) 
-- Retrieve the single highest-scoring chunk per document using QUALIFY

SELECT doc_id,
       doc_title,
       chunk_id,
       chunk_text,
       round(array_cosine_similarity(vec, [1.0, 0.0]::FLOAT[2]), 4) AS chunk_score
FROM document_chunks QUALIFY row_number() OVER (PARTITION BY doc_id
                                                ORDER BY array_cosine_similarity(vec, [1.0, 0.0]::FLOAT[2]) DESC) = 1
ORDER BY chunk_score DESC;
