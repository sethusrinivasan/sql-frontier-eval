1. Analytical Significance & What It Means

Scenario & Frontier Trap
Business Scenario & Problem

Calculates market basket association rule Lift for directional product pairs (A -> B), correctly eliminating self-pairs and evaluating directional confidence.

⚡ The Frontier Trap (Why LLMs Fail)

Naive models omit self-pair elimination (producing trivial rules like Bread -> Bread with 100% confidence), fail to normalize by total baskets, or confuse raw co-occurrence counts with statistical Lift.

Prompt / User Request Given to Model
Compute Support, Confidence, and Lift for directional association rules (Item A -> Item B):
- Support(A -> B) = Count(Transactions containing both A and B) / Total Transactions
- Confidence(A -> B) = Count(Transactions containing both A and B) / Count(Transactions containing A)
- Lift(A -> B) = Confidence(A -> B) / (Count(Transactions containing B) / Total Transactions)
Ensure self-pairs (A -> A) are excluded.

Required output columns:
- item_a (VARCHAR)
- item_b (VARCHAR)
- support (DOUBLE)
- confidence (DOUBLE)
- lift (DOUBLE)

Order by lift DESC, item_a ASC, item_b ASC.

4. Queries Executed (Candidate vs Golden Ground Truth)

Beautified & Syntax Highlighted
Candidate SQL Executed by gemini-3.8-flash-low (Runtime on 1M Rows: 112.74 ms) 
WITH basket_summary AS
  (SELECT count(DISTINCT basket_id)::DOUBLE AS total_baskets
   FROM market_baskets),
     distinct_basket_items AS
  (SELECT DISTINCT basket_id,
                   item_name
   FROM market_baskets),
     item_counts AS
  (SELECT item_name,
          count(basket_id)::DOUBLE AS item_count
   FROM distinct_basket_items
   GROUP BY item_name),
     pair_counts AS
  (SELECT a.item_name AS item_a,
          b.item_name AS item_b,
          count(a.basket_id)::DOUBLE AS pair_count
   FROM distinct_basket_items a
   JOIN distinct_basket_items b ON a.basket_id = b.basket_id
   AND a.item_name != b.item_name
   GROUP BY a.item_name,
            b.item_name)
SELECT p.item_a,
       p.item_b,
       p.pair_count / bs.total_baskets AS support,
       p.pair_count / ca.item_count AS confidence,
       (p.pair_count / ca.item_count) / (cb.item_count / bs.total_baskets) AS lift
FROM pair_counts p
CROSS JOIN basket_summary bs
JOIN item_counts ca ON p.item_a = ca.item_name
JOIN item_counts cb ON p.item_b = cb.item_name
ORDER BY lift DESC,
         p.item_a ASC,
         p.item_b ASC;
Golden Reference Ground Truth SQL (Runtime on 1M Rows: 134.47 ms) 
WITH total_orders AS
  (SELECT count(DISTINCT basket_id) AS total_baskets
   FROM market_baskets),
     item_frequencies AS
  (SELECT item_name,
          count(DISTINCT basket_id) AS item_baskets
   FROM market_baskets
   GROUP BY item_name),
     pair_occurrences AS
  (SELECT a.item_name AS item_a,
          b.item_name AS item_b,
          count(DISTINCT a.basket_id) AS pair_baskets
   FROM market_baskets a
   JOIN market_baskets b ON a.basket_id = b.basket_id
   AND a.item_name != b.item_name
   GROUP BY a.item_name,
            b.item_name)
SELECT p.item_a,
       p.item_b,
       round(p.pair_baskets * 1.0 / t.total_baskets, 4) AS support,
       round(p.pair_baskets * 1.0 / fa.item_baskets, 4) AS confidence,
       round((p.pair_baskets * 1.0 * t.total_baskets) / (fa.item_baskets * fb.item_baskets), 4) AS lift
FROM pair_occurrences p
JOIN item_frequencies fa ON p.item_a = fa.item_name
JOIN item_frequencies fb ON p.item_b = fb.item_name
CROSS JOIN total_orders t
WHERE p.pair_baskets >= 2
ORDER BY lift DESC,
         p.item_a ASC,
         p.item_b ASC;
