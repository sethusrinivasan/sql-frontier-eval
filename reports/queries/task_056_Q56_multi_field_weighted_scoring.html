4. Queries Executed (Candidate vs Golden Ground Truth)

Beautified & Syntax Highlighted

Candidate SQL Executed by gemini-3.8-flash-low (Runtime on 1M Rows: 197.27 ms) 
-- Search for 'wireless headphones': Title matches weighted 3.0x, Body matches weighted 1.0x
WITH scored AS
  (SELECT post_id,
          title,
          round((CASE
                     WHEN title ILIKE '%wireless%' THEN 3.0
                     ELSE 0.0
                 END) + (CASE
                             WHEN title ILIKE '%headphones%' THEN 3.0
                             ELSE 0.0
                         END) + (CASE
                                     WHEN BODY ILIKE '%wireless%' THEN 1.0
                                     ELSE 0.0
                                 END) + (CASE
                                             WHEN BODY ILIKE '%headphones%' THEN 1.0
                                             ELSE 0.0
                                         END), 2) AS multi_field_score
   FROM product_posts)
SELECT post_id,
       title,
       multi_field_score
FROM scored
WHERE multi_field_score > 0
ORDER BY multi_field_score DESC;
