4. Queries Executed (Candidate vs Golden Ground Truth)

Beautified & Syntax Highlighted
Candidate SQL Executed by gemini-3.8-flash-low (Runtime on 1M Rows: 135.78 ms) 
-- Search 'Headphones' in 'Audio': Hard filter available=true, soft-boost by merchant rating
WITH text_matches AS
  (SELECT item_id,
          title,
          merchant_rating, -- Base relevance score from keyword matches
 (CASE
      WHEN title ILIKE '%studio%' THEN 2.0
      ELSE 1.0
  END) AS base_relevance
   FROM merchant_inventory
   WHERE category = 'Audio'
     AND is_available = TRUE
     AND title ILIKE '%Headphones%')
SELECT item_id,
       title,
       merchant_rating,
       base_relevance,
       round(base_relevance * (1.0 + (merchant_rating / 5.0) * 0.50), 2) AS boosted_final_score
FROM text_matches
ORDER BY boosted_final_score DESC;
