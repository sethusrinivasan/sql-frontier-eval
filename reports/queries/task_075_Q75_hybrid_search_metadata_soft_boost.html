1. Analytical Significance & What It Means #

Scenario & Frontier Trap
Business Scenario & Problem

Top marketplaces enforce strict hard filters (in-stock, prime shipping) while soft-boosting items based on merchant review rating: final_score = text_relevance * (1.0 + 0.1 * merchant_rating).

⚡ The Frontier Trap (Why LLMs Fail)

Hard-filtering by rating eliminates high-relevance new merchants with few reviews.

4. Queries Executed (Candidate vs Golden Ground Truth) #

Beautified & Syntax Highlighted
Database Engine Context: This query was executed and profiled on DuckDB 2.0 In-Memory Engine with equivalent analytical syntax and execution verification on PostgreSQL 18.7 + Extensions (Docker Compose) and Amazon Aurora Serverless v2 PostgreSQL.
Candidate SQL Executed by gemini-3.8-flash-low (Runtime on 1M Rows: 117.51 ms) 
-- Search 'Headphones' in 'Audio': Hard filter available=true, soft-boost by merchant rating
WITH text_matches AS
  (SELECT item_id,
          title,
          merchant_rating, -- Base relevance score from keyword matches
 (CASE
      WHEN title ILIKE '%studio%' THEN 2.0
      ELSE 1.0
  END) AS base_relevance
   FROM merchant_inventory
   WHERE category = 'Audio'
     AND is_available = TRUE
     AND title ILIKE '%Headphones%')
SELECT item_id,
       title,
       merchant_rating,
       base_relevance,
       round(base_relevance * (1.0 + (merchant_rating / 5.0) * 0.50), 2) AS boosted_final_score
FROM text_matches
ORDER BY boosted_final_score DESC;
