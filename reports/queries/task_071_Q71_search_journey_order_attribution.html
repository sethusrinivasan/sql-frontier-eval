4. Queries Executed (Candidate vs Golden Ground Truth) #

Beautified & Syntax Highlighted
Database Engine Context: This query was executed and profiled on DuckDB 2.0 In-Memory Engine with equivalent analytical syntax and execution verification on PostgreSQL 18.7 + Extensions (Docker Compose) and Amazon Aurora Serverless v2 PostgreSQL.
Candidate SQL Executed by gemini-3.8-flash-low (Runtime on 1M Rows: 149.75 ms) 
-- Attribute purchase to the most recent search query prior to order

SELECT o.order_id,
       o.user_id,
       o.order_total,
       s.query_term AS attributing_search_query,
       s.searched_at,
       o.ordered_at
FROM completed_orders o asof
JOIN user_search_queries s ON o.user_id = s.user_id
AND o.ordered_at >= s.searched_at
ORDER BY o.order_id;
