4. Queries Executed (Candidate vs Golden Ground Truth) #

Beautified & Syntax Highlighted
Database Engine Context: This query was executed and profiled on DuckDB 2.0 In-Memory Engine with equivalent analytical syntax and execution verification on PostgreSQL 18.7 + Extensions (Docker Compose) and Amazon Aurora Serverless v2 PostgreSQL.
Candidate SQL Executed by gemini-3.8-flash-low (Runtime on 1M Rows: 2.50 ms) 
WITH RECURSIVE fraud_cluster AS
  (SELECT 101 AS seed_account,
          linked_account_id AS connected_account,
          1 AS hop_distance
   FROM shared_identifiers
   WHERE account_id = 101
   UNION ALL SELECT c.seed_account,
                    s.linked_account_id,
                    c.hop_distance + 1
   FROM fraud_cluster c
   JOIN shared_identifiers s ON c.connected_account = s.account_id
   WHERE c.hop_distance < 5)
SELECT DISTINCT seed_account,
                connected_account,
                min(hop_distance) AS shortest_hop_distance
FROM fraud_cluster
GROUP BY seed_account,
         connected_account
ORDER BY shortest_hop_distance;
Golden Reference Ground Truth SQL (Runtime on 1M Rows: 2.37 ms) 
-- Find all accounts transitively linked to known bad actor 101
 WITH RECURSIVE fraud_cluster AS
  (SELECT 101 AS seed_account,
          linked_account_id AS connected_account,
          1 AS hop_distance
   FROM shared_identifiers
   WHERE account_id = 101
   UNION ALL SELECT c.seed_account,
                    s.linked_account_id,
                    c.hop_distance + 1
   FROM fraud_cluster c
   JOIN shared_identifiers s ON c.connected_account = s.account_id
   WHERE c.hop_distance < 5)
SELECT DISTINCT seed_account,
                connected_account,
                min(hop_distance) AS shortest_hop_distance
FROM fraud_cluster
GROUP BY seed_account,
         connected_account
ORDER BY shortest_hop_distance;
