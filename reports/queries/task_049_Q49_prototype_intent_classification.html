4. Queries Executed (Candidate vs Golden Ground Truth) #

Beautified & Syntax Highlighted
Database Engine Context: This query was executed and profiled on DuckDB 2.0 In-Memory Engine with equivalent analytical syntax and execution verification on PostgreSQL 18.7 + Extensions (Docker Compose) and Amazon Aurora Serverless v2 PostgreSQL.
Candidate SQL Executed by gemini-3.8-flash-low (Runtime on 1M Rows: 418.57 ms) 
WITH ranked_intents AS
  (SELECT q.query_id,
          q.query_text,
          p.intent_name,
          array_cosine_similarity(q.query_vector, p.prototype_vector) AS intent_similarity,
          row_number() OVER (PARTITION BY q.query_id
                             ORDER BY array_cosine_similarity(q.query_vector, p.prototype_vector) DESC) AS rank_match
   FROM inbound_queries q
   CROSS JOIN intent_prototypes p)
SELECT query_id,
       query_text,
       intent_name AS predicted_intent,
       round(intent_similarity, 4) AS confidence
FROM ranked_intents
WHERE rank_match = 1
ORDER BY query_id;
Golden Reference Ground Truth SQL (Runtime on 1M Rows: 415.66 ms) 
-- Classify each query to its closest intent prototype
 WITH ranked_intents AS
  (SELECT q.query_id,
          q.query_text,
          p.intent_name,
          array_cosine_similarity(q.query_vector, p.prototype_vector) AS intent_similarity,
          row_number() OVER (PARTITION BY q.query_id
                             ORDER BY array_cosine_similarity(q.query_vector, p.prototype_vector) DESC) AS rank_match
   FROM inbound_queries q
   CROSS JOIN intent_prototypes p)
SELECT query_id,
       query_text,
       intent_name AS predicted_intent,
       round(intent_similarity, 4) AS confidence
FROM ranked_intents
WHERE rank_match = 1
ORDER BY query_id;
