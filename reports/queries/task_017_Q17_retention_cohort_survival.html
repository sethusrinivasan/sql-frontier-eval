4. Queries Executed (Candidate vs Golden Ground Truth) #

Beautified & Syntax Highlighted
Database Engine Context: This query was executed and profiled on DuckDB 2.0 In-Memory Engine with equivalent analytical syntax and execution verification on PostgreSQL 18.7 + Extensions (Docker Compose) and Amazon Aurora Serverless v2 PostgreSQL.
Candidate SQL Executed by gemini-3.8-flash-low (Runtime on 1M Rows: 89.97 ms) 
SELECT date_trunc('week', u.signup_date) AS cohort_week,
       count(DISTINCT u.user_id) AS cohort_size,
       count(DISTINCT CASE
                          WHEN a.activity_date = u.signup_date THEN u.user_id
                      END) AS day_0_active,
       count(DISTINCT CASE
                          WHEN a.activity_date >= u.signup_date + 7
                               AND a.activity_date < u.signup_date + 14 THEN u.user_id
                      END) AS day_7_active,
       count(DISTINCT CASE
                          WHEN a.activity_date >= u.signup_date + 14
                               AND a.activity_date < u.signup_date + 21 THEN u.user_id
                      END) AS day_14_active
FROM app_users u
LEFT JOIN activity_log a ON u.user_id = a.user_id
GROUP BY cohort_week
ORDER BY cohort_week;
Golden Reference Ground Truth SQL (Runtime on 1M Rows: 90.14 ms) 
-- Generate dynamic cohort retention matrix

SELECT date_trunc('week', u.signup_date) AS cohort_week,
       count(DISTINCT u.user_id) AS cohort_size,
       count(DISTINCT CASE
                          WHEN a.activity_date = u.signup_date THEN u.user_id
                      END) AS day_0_active,
       count(DISTINCT CASE
                          WHEN a.activity_date >= u.signup_date + 7
                               AND a.activity_date < u.signup_date + 14 THEN u.user_id
                      END) AS day_7_active,
       count(DISTINCT CASE
                          WHEN a.activity_date >= u.signup_date + 14
                               AND a.activity_date < u.signup_date + 21 THEN u.user_id
                      END) AS day_14_active
FROM app_users u
LEFT JOIN activity_log a ON u.user_id = a.user_id
GROUP BY cohort_week
ORDER BY cohort_week;
