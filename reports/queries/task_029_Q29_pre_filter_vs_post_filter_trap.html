1. Analytical Significance & What It Means

Scenario & Frontier Trap
Business Scenario & Problem

A user searches for 'cheap mechanical keyboard under $50'. If you run vector search Top-K first and filter by price afterwards (post-filtering), you may return zero products because all top-5 matches were $150 keyboards.

⚡ The Frontier Trap (Why LLMs Fail)

Post-filtering vector results breaks recall. Relational constraints (in-stock, price bounds, user tenant_id) must be evaluated as PRE-FILTERS before Top-K ranking.

Prompt / User Request Given to Model

4. Queries Executed (Candidate vs Golden Ground Truth)

Beautified & Syntax Highlighted
Database Engine Context: This query was executed and profiled on DuckDB 2.0 In-Memory Engine with equivalent analytical syntax and execution verification on PostgreSQL 18.7 + Extensions (Docker Compose).
Candidate SQL Executed by gemini-3.8-flash-low (Runtime on 1M Rows: 8.05 ms) 
SELECT item_id,
       name,
       price,
       round(array_cosine_similarity(vector, [0.9, 0.1, 0.1]::FLOAT[3]), 4) AS similarity
FROM inventory_items
WHERE in_stock = TRUE
  AND price <= 50.00
ORDER BY similarity DESC
LIMIT 2;
