1. Analytical Significance & What It Means

Scenario & Frontier Trap
Business Scenario & Problem

HR analytics measures how deep the management chain is from the CEO to individual contributors and calculates direct vs indirect headcounts for each manager.

⚡ The Frontier Trap (Why LLMs Fail)

Unbounded recursive queries crash if there is an accidental circular reporting loop (e.g. A reports to B, B reports to A).

4. Queries Executed (Candidate vs Golden Ground Truth)

Beautified & Syntax Highlighted
Database Engine Context: This query was executed and profiled on DuckDB 2.0 In-Memory Engine with equivalent analytical syntax and execution verification on PostgreSQL 18.7 + Extensions (Docker Compose).
Candidate SQL Executed by gemini-3.8-flash-low (Runtime on 1M Rows: 0.89 ms) 
WITH RECURSIVE employee_hierarchy AS
  (-- Anchor member: Start with top-level employees (CEO / no manager)
 SELECT emp_id,
        emp_name,
        1 AS hierarchy_level,
        cast(emp_name AS VARCHAR) AS reporting_path
   FROM employees
   WHERE manager_id IS NULL
   UNION ALL -- Recursive member: Traverse down reporting chains
 SELECT e.emp_id,
        e.emp_name,
        eh.hierarchy_level + 1 AS hierarchy_level,
        eh.reporting_path || ' -> ' || e.emp_name AS reporting_path
   FROM employees e
   JOIN employee_hierarchy eh ON e.manager_id = eh.emp_id)
SELECT emp_id,
       emp_name,
       hierarchy_level,
       reporting_path
FROM employee_hierarchy
ORDER BY hierarchy_level,
         emp_id;
Golden Reference Ground Truth SQL (Runtime on 1M Rows: 0.91 ms) 
-- Traverse management tree from CEO downward, tracking reporting depth
 WITH RECURSIVE org_hierarchy AS
  (SELECT emp_id,
          emp_name,
          manager_id,
          1 AS hierarchy_level,
          emp_name AS reporting_path
   FROM employees
   WHERE manager_id IS NULL
   UNION ALL SELECT e.emp_id,
                    e.emp_name,
                    e.manager_id,
                    h.hierarchy_level + 1,
                    h.reporting_path || ' -> ' || e.emp_name
   FROM employees e
   JOIN org_hierarchy h ON e.manager_id = h.emp_id)
SELECT emp_id,
       emp_name,
       hierarchy_level,
       reporting_path
FROM org_hierarchy
ORDER BY hierarchy_level,
         emp_id;
