4. Queries Executed (Candidate vs Golden Ground Truth)

Beautified & Syntax Highlighted
Candidate SQL Executed by gemini-3.8-flash-low (Runtime on 1M Rows: 0.66 ms) 
SELECT a.doc_id AS doc_a,
       b.doc_id AS doc_b,
       a.bucket_id,
       round(array_cosine_similarity(a.vector, b.vector), 4) AS similarity
FROM corpus a
JOIN corpus b ON a.bucket_id = b.bucket_id
AND a.doc_id < b.doc_id
WHERE array_cosine_similarity(a.vector, b.vector) >= 0.85
ORDER BY similarity DESC;
Golden Reference Ground Truth SQL (Runtime on 1M Rows: 0.55 ms) 
-- Pairwise similarity evaluated ONLY within shared bucket partitions

SELECT a.doc_id AS doc_a,
       b.doc_id AS doc_b,
       a.bucket_id,
       round(array_cosine_similarity(a.vector, b.vector), 4) AS similarity
FROM corpus a
JOIN corpus b ON a.bucket_id = b.bucket_id
AND a.doc_id < b.doc_id
WHERE array_cosine_similarity(a.vector, b.vector) >= 0.85
ORDER BY similarity DESC;
