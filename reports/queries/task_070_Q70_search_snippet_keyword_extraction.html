1. Analytical Significance & What It Means #

Scenario & Frontier Trap
Business Scenario & Problem

Search results show a preview snippet containing the searched keyword with 30 characters of surrounding context rather than the beginning of a 2,000-word article.

⚡ The Frontier Trap (Why LLMs Fail)

Substring extraction crashes when matching keywords appear near the very beginning or end of the text.

Prompt / User Request Given to Model
Search results show a preview snippet containing the searched keyword with 30 characters of surrounding context rather than the beginning of a 2,000-word article.

Execute the required analytical SQL calculation in DuckDB.
Expected output columns: post_id, snippet_preview.
Row order does not matter.

4. Queries Executed (Candidate vs Golden Ground Truth) #

Beautified & Syntax Highlighted
Database Engine Context: This query was executed and profiled on DuckDB 2.0 In-Memory Engine with equivalent analytical syntax and execution verification on PostgreSQL 18.7 + Extensions (Docker Compose) and Amazon Aurora Serverless v2 PostgreSQL.
Candidate SQL Executed by gemini-3.8-flash-low (Runtime on 1M Rows: 468.50 ms) 
SELECT post_id,
       '...' || substring(content, greatest(1, instr(lower(content), 'vectorized') - 15), length('vectorized') + 30) || '...' AS snippet_preview
FROM blog_posts
WHERE content ILIKE '%vectorized%';
