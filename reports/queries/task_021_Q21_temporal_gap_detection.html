4. Queries Executed (Candidate vs Golden Ground Truth)

Beautified & Syntax Highlighted
Database Engine Context: This query was executed and profiled on DuckDB 2.0 In-Memory Engine with equivalent analytical syntax and execution verification on PostgreSQL 18.7 + Extensions (Docker Compose).
Candidate SQL Executed by gemini-3.8-flash-low (Runtime on 1M Rows: 46.28 ms) 
WITH lease_boundaries AS
  (SELECT vehicle_id,
          lease_end AS gap_start,
          lead(lease_start) OVER (PARTITION BY vehicle_id
                                  ORDER BY lease_start) AS gap_end
   FROM vehicle_leases)
SELECT vehicle_id,
       gap_start,
       gap_end,
       (gap_end - gap_start) AS idle_days
FROM lease_boundaries
WHERE gap_end IS NOT NULL
  AND gap_end > gap_start
ORDER BY vehicle_id,
         gap_start;
Golden Reference Ground Truth SQL (Runtime on 1M Rows: 41.04 ms) 
-- Identify idle intervals between vehicle leases
 WITH lease_boundaries AS
  (SELECT vehicle_id,
          lease_end AS gap_start,
          lead(lease_start) OVER (PARTITION BY vehicle_id
                                  ORDER BY lease_start) AS gap_end
   FROM vehicle_leases)
SELECT vehicle_id,
       gap_start,
       gap_end,
       (gap_end - gap_start) AS idle_days
FROM lease_boundaries
WHERE gap_end IS NOT NULL
  AND gap_end > gap_start
ORDER BY vehicle_id,
         gap_start;
