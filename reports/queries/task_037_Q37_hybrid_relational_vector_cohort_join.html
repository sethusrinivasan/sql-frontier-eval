1. Analytical Significance & What It Means #

Scenario & Frontier Trap
Business Scenario & Problem

Real-world matchmaking (dating apps, gig-economy driver matching) requires vector personality/skill compatibility joined with strict relational geographic and category boundaries.

⚡ The Frontier Trap (Why LLMs Fail)

Matching vectors globally without partitioning by region produces candidates located 3,000 miles away.

4. Queries Executed (Candidate vs Golden Ground Truth) #

Beautified & Syntax Highlighted
Database Engine Context: This query was executed and profiled on DuckDB 2.0 In-Memory Engine with equivalent analytical syntax and execution verification on PostgreSQL 18.7 + Extensions (Docker Compose) and Amazon Aurora Serverless v2 PostgreSQL.
Candidate SQL Executed by gemini-3.8-flash-low (Runtime on 1M Rows: 64.61 ms) 
SELECT j.job_id,
       j.region,
       c.candidate_id,
       round(array_cosine_similarity(c.skills_vec, j.required_vec), 4) AS skill_fit_score
FROM job_openings j
JOIN candidates c ON j.region = c.region
ORDER BY skill_fit_score DESC;
Golden Reference Ground Truth SQL (Runtime on 1M Rows: 65.55 ms) 
-- Match jobs to candidates strictly within matching geographical region ordered by skill compatibility

       j.region,
       c.candidate_id,

FROM job_openings j
JOIN candidates c ON j.region = c.region
ORDER BY skill_fit_score DESC;
