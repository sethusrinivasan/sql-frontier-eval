4. Queries Executed (Candidate vs Golden Ground Truth)

Beautified & Syntax Highlighted
Candidate SQL Executed by gemini-3.8-flash-low (Runtime on 1M Rows: 98.80 ms) 
SELECT j.job_id,
       j.region,
       c.candidate_id,
       round(array_cosine_similarity(c.skills_vec, j.required_vec), 4) AS skill_fit_score
FROM job_openings j
JOIN candidates c ON j.region = c.region
ORDER BY skill_fit_score DESC;
Golden Reference Ground Truth SQL (Runtime on 1M Rows: 91.67 ms) 
-- Match jobs to candidates strictly within matching geographical region ordered by skill compatibility

SELECT j.job_id,
       j.region,
       c.candidate_id,
       round(array_cosine_similarity(c.skills_vec, j.required_vec), 4) AS skill_fit_score
FROM job_openings j
JOIN candidates c ON j.region = c.region
ORDER BY skill_fit_score DESC;
