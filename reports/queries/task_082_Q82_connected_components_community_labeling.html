4. Queries Executed (Candidate vs Golden Ground Truth)

Beautified & Syntax Highlighted
Database Engine Context: This query was executed and profiled on DuckDB 2.0 In-Memory Engine with equivalent analytical syntax and execution verification on PostgreSQL 18.7 + Extensions (Docker Compose).
Candidate SQL Executed by gemini-3.8-flash-low (Runtime on 1M Rows: 2.00 ms) 
-- Symmetric edges
WITH RECURSIVE symmetric_edges AS
  (SELECT node_a AS src,
          node_b AS dst
   FROM graph_edges
   UNION SELECT node_b AS src,
                node_a AS dst
   FROM graph_edges),
               components AS
  (-- Anchor: Initial component label is node itself
 SELECT src AS node_id,
        src AS component_id,
        0 AS iteration
   FROM symmetric_edges
   UNION ALL -- Propagate smaller component ID across edges
 SELECT e.dst AS node_id,
        c.component_id,
        c.iteration + 1
   FROM components c
   JOIN symmetric_edges e ON c.node_id = e.src
   WHERE c.component_id < e.dst
     AND c.iteration < 5)
SELECT node_id,
       min(component_id) AS cluster_id
FROM components
GROUP BY node_id
ORDER BY cluster_id,
         node_id;
