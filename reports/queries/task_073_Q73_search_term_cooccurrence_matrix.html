Scenario & Frontier Trap
Business Scenario & Problem

To suggest related searches, engines analyze queries searched together in the same session (e.g. users searching 'monitor' also search 'hdmi cable' 42% of the time).

Self-joining search sessions without ordering (`a.term < b.term`) doubles matrix size with duplicate reversed pairs.

4. Queries Executed (Candidate vs Golden Ground Truth)

Beautified & Syntax Highlighted
Candidate SQL Executed by gemini-3.8-flash-low (Runtime on 1M Rows: 0.87 ms) 
SELECT a.term AS term_a,
       b.term AS term_b,
       count(*) AS cooccurrence_count
FROM session_searches a
JOIN session_searches b ON a.session_id = b.session_id
AND a.term < b.term
GROUP BY a.term,
         b.term
ORDER BY cooccurrence_count DESC,
         term_a,
         term_b;
Golden Reference Ground Truth SQL (Runtime on 1M Rows: 0.92 ms) 
-- Find pairs of terms most frequently searched in the same user session

SELECT a.term AS term_a,
       b.term AS term_b,
       count(*) AS cooccurrence_count
FROM session_searches a
JOIN session_searches b ON a.session_id = b.session_id
AND a.term < b.term
GROUP BY a.term,
         b.term
ORDER BY cooccurrence_count DESC,
         term_a,
         term_b;
