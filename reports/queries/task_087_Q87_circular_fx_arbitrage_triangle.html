4. Queries Executed (Candidate vs Golden Ground Truth)

Beautified & Syntax Highlighted
Candidate SQL Executed by gemini-3.8-flash-low (Runtime on 1M Rows: 0.26 ms) 
SELECT leg1.from_curr AS curr_start,
       leg1.to_curr AS curr_mid1,
       leg2.to_curr AS curr_mid2,
       leg3.to_curr AS curr_end,
       leg1.exchange_rate * leg2.exchange_rate * leg3.exchange_rate AS loop_multiplier,
       (leg1.exchange_rate * leg2.exchange_rate * leg3.exchange_rate - 1.0) * 100.0 AS profit_margin_pct
FROM fx_pairs AS leg1
JOIN fx_pairs AS leg2 ON leg1.to_curr = leg2.from_curr
JOIN fx_pairs AS leg3 ON leg2.to_curr = leg3.from_curr
WHERE leg1.from_curr = leg3.to_curr
  AND leg1.exchange_rate * leg2.exchange_rate * leg3.exchange_rate > 1.0;
Golden Reference Ground Truth SQL (Runtime on 1M Rows: 0.28 ms) 
-- Detect 3-hop triangular arbitrage opportunities where effective rate > 1.005

SELECT a.from_curr AS curr_start,
       a.to_curr AS curr_mid1,
       b.to_curr AS curr_mid2,
       c.to_curr AS curr_end,
       round(a.exchange_rate * b.exchange_rate * c.exchange_rate, 4) AS loop_multiplier,
       round((a.exchange_rate * b.exchange_rate * c.exchange_rate - 1.0) * 100, 2) AS profit_margin_pct
FROM fx_pairs a
JOIN fx_pairs b ON a.to_curr = b.from_curr
JOIN fx_pairs c ON b.to_curr = c.from_curr
AND c.to_curr = a.from_curr
WHERE (a.exchange_rate * b.exchange_rate * c.exchange_rate) > 1.005;
