SQL-Frontier-Eval

Benchmarking Frontier AI on Complex Analytical SQL & Silent Metric Corruption

Evaluating semantic correctness, mathematical KPI integrity, and plan efficiency on modern analytical engines (DuckDB, Snowflake, BigQuery, Databricks).

📌 The Core Problem

Textbook Text-to-SQL benchmarks only test syntax and basic relational lookups. In production warehouses, LLMs generate silent metric inflation and computational row explosions with zero syntax errors.

🏗️ Hardened Architecture

DuckDB in-memory isolation, deterministic multiset row matching, floating-point numeric tolerance, and EXPLAIN JSON physical operator traversal.

Failure Taxonomy

The 8-Category Analytical Failure Taxonomy

01. The Chasm Trap

Joining multiple 1:N child tables before GROUP BY multiplies base metrics (e.g. 4x gross sales).

02. Gaps & Islands

Web analytics 30-min inactivity sessionization requiring cumulative step flags.

03. SCD Type 2 Point-in-Time

Historical currency conversion rates where missing valid_to IS NULL drops ongoing rows.

04. Three-Valued Logic

Anti-joins using NOT IN over subqueries with NULLs silently returning 0 rows.

05. Window Frame Bounds

Default RANGE frame improperly bunching duplicate timestamp transactions together.

06. Strict Funnel Precedence

Multi-stage conversion funnels requiring strict chronological step order.

07. Quadratic Self-Joins

Triangular joins on rolling metrics triggering O(N²) memory spills instead of window scans.

08. Non-SARGable Pruning

Date function wrapping defeating columnar partition min/max pruning.
